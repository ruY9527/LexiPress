这个站点做什么

{{ site.title }} 是一个本地 Python 驱动 + GitHub Actions 自动发布的英文外刊精读系统。 它从 RSS / Atom 与 Hacker News 等高质量外刊源采集文章，经过 URL 归一化、双重去重、 trafilatura 正文抽取与付费墙检测后，按「来源权重 × 时效性 × 篇幅适配度」综合打分， 精选出最值得读的文章。

精读解析采用两阶段结构化 LLM 调用：先分批带显式 index 翻译逐段对照， 杜绝中英错位；再全篇提炼导读、语境生词与长难句拆解，并用 Pydantic v2 强校验与重试保障质量。 未配置 LLM_API_KEY 时自动降级为规则模式，站点照常发布。

前台以 Editorial Luxury 高端杂志美学呈现：三套护眼主题、玻璃拟态顶栏、Cmd+K 全局搜索、 Hero 头版与印刷排版艺术封面兜底、沉浸式双栏精读、生词浮窗发音、词表联动、盲读保护罩， 以及 LocalStorage 生词本（支持一键导出 Anki CSV / Markdown）。

职责边界清晰：采集、解析与本地可视化后台只在本地运行； GitHub Actions 仅负责将已就绪的博客源文件以 --build-only 渲染为静态站并部署。

01 · Harvest 多源采集、URL 归一化、双重去重、正文精准抽取与付费墙识别。
02 · Understand 两阶段 LLM 精读：逐段双语对齐、语境生词、长难句语法拆解。
03 · Read 杂志风沉浸阅读：三主题、生词浮窗发音、盲读保护与学习工作台。
04 · Publish GitHub Actions 纯渲染发布，本地数据即真理源，零后端依赖。

项目提示词

如果用一句话给 AI 下指令来构建这个项目，它就是下面这段提示词：

Build LexiPress: a Python + LLM English reading studio. Harvest RSS/HN → dedupe → trafilatura extract → score → two-stage LLM (indexed paragraph translation + vocab/sentence breakdown, Pydantic-validated, rule-only fallback) → editorial-luxury Jinja2 site with 3 themes, Cmd+K search, vocab popover & Anki export → GitHub Pages via Actions.

中文版：搭建 LexiPress —— Python + LLM 英文精读工坊。多源采集 → URL 去重 → 正文抽取 → 综合打分 → 两阶段 LLM（带 index 的逐段翻译 + 生词/长难句提炼，Pydantic 校验，失败自动规则降级）→ 高端杂志风静态站（三主题、Cmd+K 搜索、生词浮窗、Anki 导出）→ GitHub Actions 自动发布。
